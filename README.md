## Stack
Plain HTML/CSS/JS — no build step. `index.html` is the entire site.

## Deploy
- **Netlify:** drag this folder into app.netlify.com/drop, or connect this repo (no build command, publish directory = root)
- **GitHub Pages:** Settings → Pages → Deploy from branch → main → / (root)
